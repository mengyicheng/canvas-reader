# 画布阅读 · Wander & Read

像画布一样管理你的读书笔记。一款**无限画布 AI 阅读软件**：读、注、连、问，在同一处完成。

- 导入书籍即可阅读，进度自动记录，下次打开回到上次读到的段落。
- 框选任意文字，随时向 AI 提问；内置 AI 总结 / 翻译 / 解释 / 大纲 / 问题 等预设。
- 边注、划线、书签、反向链接，把零散笔记串成知识网络（画布）。
- 概念图谱自动提炼书中核心概念，辅助建立全局认知。

> 当前版本：**v0.2.0**（尚未发布 1.0）。

---

## 功能特性

**阅读与导入**
- 支持导入 **EPUB / Markdown(.md) / TXT / PDF**。
- 导入的 Markdown 会保留标题、加粗、列表、代码块、表格、引用等排版，不再显示为裸符号。
- 打开书籍自动恢复上次阅读位置（基于段落锚点）。

**AI 能力（需自备 API）**
- **询问 AI**：以选中内容为背景，自由向 AI 提问。
- **AI 功能栏**：AI 总结 / 翻译 / 解释 / 大纲 / 问题 五个预设，单击展开，每个按钮标注其作用与背景范围（全书 / 选中）。
- AI 回答**流式输出**，并显示 0→100 进度条；回答支持 **Markdown 渲染**（加粗、列表、代码块、表格等）。
- 后台走 OpenAI 兼容接口，API Key 由用户在使用时自填，**不随安装包分发**。

**笔记与知识**
- 边注、划线、书签、反向链接（反链）。
- 画布（Canvas）：把跨文章的笔记与概念连成知识网络。
- 概念图谱：自动提炼书中核心概念（已做停用词过滤，聚焦中心思想与关键字）。
- 复习 / 闪卡：可基于笔记显式生成复习卡。

**界面**
- 强制深色模式（亮色配色未适配，已移除）。
- 顶部导航中文化（阅读 / 画布 / 复习 / 概念 / 设置）；点「阅读」回到正在读的书，点品牌标志回到书库首页。
- 右侧栏宽度可鼠标拖动调整；滚动条已适配深色主题。

## 技术栈

| 层 | 技术 |
| --- | --- |
| 桌面框架 | Tauri v2 |
| 前端 | React 18 + Vite 5 + TypeScript |
| 原生层 | Rust（`src-tauri`，Cargo） |
| PDF 解析 | `pdfjs-dist` |

> 采用 Tauri 桌面架构（而非纯网页），以规避网页端打包后环境不一致的风险。

---

## 环境要求

| 依赖 | 说明 |
| --- | --- |
| Node.js | 建议 20+（管理运行时 22.x 可用） |
| Rust + Cargo | 1.97+ |
| C 链接器 | **Windows**：MSVC Build Tools 或 MinGW（打包必需） |
| 系统 | Windows 10 / 11 |

> ⚠️ 打包（生成 `.msi` / `.exe`）必须在装有 C 链接器的机器上执行；仅运行开发模式也需要 Rust 工具链。

---

## 快速开始

```bash
# 1. 安装前端依赖
npm install

# 2. 启动开发模式（会拉起 Tauri 桌面窗口）
npm run tauri dev
# 或双击仓库内的 run-dev.cmd

# 3. 打包发布（生成安装包）
npm run tauri build
# 或双击仓库内的 build.cmd
```

打包产物位置：
- MSI：`src-tauri/target/release/bundle/msi/`
- NSIS 安装包：`src-tauri/target/release/bundle/nsis/`

---

## 配置 API Key

1. 打开应用 → 顶部「设置」。
2. 填入你的 API Base URL 与 API Key（OpenAI 兼容格式）。
3. 保存后即可使用 AI 功能。Key 仅存于本机，不随安装包分发。
